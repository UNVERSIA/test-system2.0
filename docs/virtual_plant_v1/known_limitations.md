# 已知限制

1. 所有水厂尺寸、容量、坐标、测点初值和设备额定参数均为示范配置，待竣工图、设备清单和SCADA点表校准。
2. 水质只做无反应完全混合传播；没有经过验证的COD、氮、磷、SS去除动力学。
3. DO反馈、设备能耗和甲烷风险阈值未取得合格来源或设备曲线，状态分别为 `awaiting_calibration` / `awaiting_source`。
4. 当前后端引擎实例驻留单进程内存；多进程部署前需要引入外部状态协调，但V1不引入Redis或数据库重构。
5. `UPLOADED` 和 `LIVE` 只有统一模型边界，尚未接入离线文件映射和SCADA。
6. 程序化V1模型用于设施辨识和交互，不是竣工级BIM/GIS模型。
7. 前端主包存在超过500 kB的构建警告；功能不受影响，后续可在不改变状态边界的前提下做代码分包。
8. Python环境存在既有Requests依赖版本警告；测试可通过，但后续应在锁定环境中整理依赖。

# 仿真边界

## V1做什么

- 使用统一的1分钟工艺时间步；浏览器帧率不参与工艺计算。
- 在水线连接上执行储量、入流和出流的离散守恒。
- 对COD、氨氮、TN、TP、SS、DO、pH和温度执行无反应、完全混合的配置化传播。
- 设备启停、故障、维护和手/自动模式进入统一状态。
- 泵送能力影响主水线通量；鼓风机状态影响DO演示值；运行设备产生示范能耗。
- 甲烷示范状态影响风险颜色、测点、趋势和告警。

## V1不做什么

- 不声称为ASM、ADM或其他经校准生化机理模型。
- 不凭经验添加COD、氮、磷或SS去除率。
- 不把B0、MCF、GWP或旧代码中的排放因子视为已验证事实。
- 不模拟真实设备效率曲线、泵扬程曲线或风机性能曲线。
- 不提供控制决策、安全联锁、合规判断或真实生产调度依据。

## 边界与告警

液位限制为0–100%。计算储量超出有效容积时会截断至容量、把单元标记为 `blocked` 并产生高液位/不可用告警；停运单元出流为0并产生积累。

所有未校准关系使用 `provisional`、`awaiting_source` 或 `awaiting_calibration`，不会因为缺少科学来源而阻塞软件和可视化闭环。

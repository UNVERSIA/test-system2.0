# 单位表

| 量 | API/代码单位 | 页面单位 | 说明 |
|---|---|---|---|
| 仿真时间 | min | HH:MM / min | 固定1分钟步长 |
| 有效容积/储量 | m³ | m³ | 单元容量与当前储量 |
| 流量 | m³/d | m³/d | 步内换算使用 `Δt/1440` |
| 液位 | % | % | 0–100 |
| COD、氨氮、TN、TP、SS、DO | mg/L | mg/L | V1只做守恒传播或演示反馈 |
| pH | 无量纲 | pH | V1按状态传播，不做酸碱平衡 |
| 温度 | °C | °C | V1按状态传播 |
| 甲烷示范值 | mg/L | mg/L | 不等同于排放量或合规浓度 |
| 功率 | kW | kW | 示例额定功率与负荷 |
| 电耗 | kWh | kWh | 累计示范能耗 |
| 鼓风机频率 | Hz | Hz | 待具体设备曲线校准 |
| 设备速度/投加量 | %或配置单位 | 同配置 | 上下限来自水厂配置 |

API、Pinia和页面不进行隐式单位变换；所有可调设备同时返回 `parameter_unit`。

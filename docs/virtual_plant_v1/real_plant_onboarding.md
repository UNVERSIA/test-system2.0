# 后续接入真实水厂数据的方法

唯一建议的接入顺序：**先完成一座真实水厂的配置与数据字典校准，再扩展模型复杂度。**

## 所需资料

1. 工艺流程图、总平面图、池体有效尺寸和高程；
2. 设备清单、铭牌参数、泵/风机性能曲线和控制范围；
3. SCADA/PLC点表、采样周期、时间戳规则、量程、坏值码和质量标识；
4. 实验室检测指标、方法、频次和数据质量规则；
5. 告警阈值、联锁边界和操作规程；
6. 甲烷测点布置、仪表原理、校准记录和合规目的；
7. 要采用的IWA/IPCC/国家或行业标准的完整版本、章节、公式和表格定位。

## 实施步骤

1. 复制 `demo_plant.json`，替换ID、尺寸、拓扑、测点和设备，不先修改Three.js组件。
2. 建立外部点位到 `SensorState` / `EquipmentState` 的映射和单位转换测试。
3. 将模式切换到 `UPLOADED` 做离线回放，对齐时间戳、缺失值和坏值。
4. 用质量守恒和历史曲线验证状态传播；确认后再接入只读 `LIVE`。
5. 每条新增公式先进入注册表，补齐正式来源和测试；只有验证与校准完成后才标记 `verified`。
6. 在影子模式完成比对和人工验收后，才讨论闭环控制；V1不得直接下发生产控制指令。

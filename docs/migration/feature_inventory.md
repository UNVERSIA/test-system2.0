# 原 Streamlit 功能清单

审计基线：`GitHub/app.py`，分支 `migration/vue-fastapi-parity`。旧版已在 Windows Python 3.10.14 环境启动，`http://localhost:8501` 返回 200；启动日志显示 TensorFlow 不可用，预测模块进入备用模式提示。

## 全局侧边栏

- Excel 上传：`上传运行数据（Excel）`，仅 `.xlsx`；自动识别多级表头、单级表头和日数据，日数据按 30 倍转换为月数据；成功后选择月份。
- 工艺优化模拟：曝气时间调整 `%`（-30 至 30，默认 0）、PAC 投加量调整 `%`（-20 至 20，默认 0）、污泥回流比（0.30 至 0.80，步长 0.05，默认 0.50）。
- 动态效果：启用动态水流效果（默认开启）、水流速度（1000 至 20000，默认 10000）。
- 高级操作：更新电力排放因子、生成模拟数据、重置甲烷因子数据库。
- 数字人设置：测试 Coze 连接、清空当前对话、导出历史对话；缺少配置时显示真实错误/回退提示。

## 十个功能页

### 1. 3D水厂仿真

标题为 `3D 水厂数字孪生虚拟仿真`。Three.js 场景使用 `assets/models/wanzi_web.glb` 及既有设备配置、相机、灯光、水面和动画。场景内提供重置视角、自动旋转、水面效果和设备选择。工艺区参数编辑包含选择工艺区、甲烷浓度、流量、液位、温度、pH、运行状态和 `保存参数修改`；显示选中设备甲烷排放、能耗、全厂总排放/处理水量/能耗/运行单元，以及高/中/一般/正常风险统计。

### 2. 工艺流程仿真

标题为 `2D水厂工艺流程仿真`。保留原工艺拓扑、组件状态、动态水流和 iframe 编辑器。编辑器控件：新组件名称、组件类型（预处理/生物处理/深度处理/污泥处理/辅助设施/出水设施）、添加组件、组件说明文字、修改说明文字、管线类型（水流/污泥/臭气/空气）、管线标注、连接组件、删除所选、清空画布、恢复原始流程、分区名称、分区颜色、添加/修改/删除分区。右侧工艺单元选择、启用单元、处理水量、能耗；厌氧/缺氧/好氧额外有 TN/COD 进出水，DF 有 PAC，污泥车间有 PAM；显示排放、状态、详情描述、运行笔记及单元说明。

### 3. 甲烷足迹追踪

标题为 `甲烷足迹追踪与评估`。上传数据后调用直接排放、间接排放、工艺单元拆分，显示全流程排放热力图、甲烷动态追踪 Sankey 图和排放效率排行榜；无数据时显示 `请先上传运行数据`。

### 4. 甲烷账户管理

标题为 `甲烷账户管理`。有核算数据时显示当月各工艺区的甲烷流入、流出、净排放明细、总排放/抵消/净排放/处理水量/单位排放/效率/能源中和率/减排率等指标，并提供账户趋势、抵消技术选择和图表；无数据时显示 `请先上传运行数据`。

### 5. 优化与决策

标题为 `优化与决策支持`。基于当前数据执行 `OptimizationEngine` 的参数优化、情景模拟、敏感性分析和工艺调整建议，显示优化前后排放、减排率、目标达成、敏感性图和方案对比；无数据时显示 `请先上传运行数据`。

### 6. 甲烷排放预测

标题为 `甲烷排放趋势预测`。模型管理按钮 `加载预训练模型`；模型训练按钮 `训练新模型`；预测时长选择（1/3/6/12 个月，默认 12）；`进行预测`；显示预测范围、历史数据范围、模型状态、预测表格和历史/预测趋势图。TensorFlow 或模型不可用时保留备用预测路径和真实错误提示。

### 7. 减排技术分析

标题为 `甲烷减排技术对比分析`。多选技术（厌氧消化产沼、光伏发电、高效曝气、热泵技术、污泥干化、沼气发电）；`运行技术对比分析`；技术说明、技术适用性详情（年减排量、投资成本、回收期、适用性、减排贡献率、能源中和率）；抵消计算输入沼气发电量、光伏发电量、热泵节能量、污泥资源化量，显示总抵消量。

### 8. 因子库管理

标题为 `甲烷排放因子库管理`。显示当前因子表和来源说明；因子类型、电力/PAC/PAM/次氯酸钠/臭氧/N2O/CH4，因子值，生效年份（2020-2025），`更新因子`；电力因子历史趋势；CSV/Excel 导出；显示运行模式、因子总数、数据来源。数据库不可用时使用与旧版一致的回退默认值并禁用更新。

### 9. 数字人助手

标题为 `污水处理智能助手`。显示烷仔模型、欢迎信息、5 个快捷问题、对话历史和文本输入；发送消息调用 `CozeAPI.chat`，支持会话 ID、流式响应、历史清空和 JSON 导出；缺少 `COZE_AGENT_TOKEN`/`COZE_PROJECT_ID` 时显示配置错误。

### 10. AI实验室·污水处理闯关

保留 5 个关卡、原题目/图片/选项、拖拽排序、提交、重置、撤销上一步、下一关、计分、进度和解锁状态；图片来自 `GitHub/assets`，游戏状态由 `water_treatment_game.py` 管理。
